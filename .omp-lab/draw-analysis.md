# Draw Prediction Calibration Analysis

## Обзор

Анализ калибровки прогнозов ничьих (DRAW) в Poisson анализаторе. Источники данных: PostgreSQL (`games` + `leagues`), результаты baseline backtest, код `src/analytics/analyzers/poisson.js`.

---

## 1. Текущий механизм Draw Boost (`poisson.js`, строки 216-227)

```js
const lambdaDiff = Math.abs(lambdaHome - lambdaAway);
if (lambdaDiff < 0.3) {
    const drawBoost = (1 - lambdaDiff / 0.3) * 0.10; // up to +10%
    pDraw += drawBoost;
    // пропорционально уменьшает pHome и pAway
}
```

| Параметр | Значение |
|---|---|
| Порог `|λ_home - λ_away|` | < 0.3 |
| Макс. буст | +0.10 (10 процентных пунктов) |
| Формула буста | линейный: `(1 - diff/0.3) * 0.10` |
| Перераспределение | `pHome` и `pAway` уменьшаются пропорц. |

**Проблема**: Буст прибавляет до +10pp к pDraw, но реальный дефицит прогноза ничьих составляет **+15..+25pp** — текущий буст покрывает менее половины необходимого.

**Причина**: Ensemble prediction (`predictFromAnalyzers`) взвешивает Poisson (60%), markov_outcome (15%), form_inertia (10%), HMM (15%). Даже когда Poisson даёт `pDraw ≈ 25-30%`, другие анализаторы добавляют вес к HOME/AWAY, и итоговый прогноз становится HOME.

## 5. Рекомендации

### 5.1. Немедленные

1. **Увеличить cap draw boost с 0.10 до 0.25-0.30** для всех лиг (это покроет средний дефицит 3x).

## 6. Ограничения анализа

- Backtest использует **100 матчей** на лигу/сезон — малая выборка для DRAW, особенно в лигах с редкими прогнозами ничьих (Bundesliga: 3/200).
- Backtest меряет **классификацию** (DRAW как исход), не среднюю вероятность pDraw. Для точной калибровки нужно логировать `pDraw` по каждому матчу.
- `DRAW.predicted` и `DRAW.actual` в backtest совпадают из-за бага в `strategies-routes.js:694` (инкремент `actual` по `predicted`).
- Не учитывается сезонность — внутри сезона частота ничьих может меняться (начало vs конец сезона).
- Dixon-Coles ρ = -0.10 может быть неоптимальным для отдельных лиг.

---

## 7. Итог

**Систематическое недооценивание ничьих — главный дефект текущей модели.** Реальная частота DRAW = 23-33%, модель прогнозирует DRAW как исход в 1-26% случаев. Текущий draw boost (+10pp) недостаточен: необходим буст в диапазоне +15..+50pp с per-league калибровкой.

**Приоритет**: увеличить max_boost до 0.25-0.30 глобально, затем внедрить per-league мультипликаторы через `league_calibration` таблицу.
