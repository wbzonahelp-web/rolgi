## ✅ Что сделано

Успешно завершена **Phase 1** улучшения системы прогнозирования rolgi:

### Критические исправления
1. **Баг с весами (ИСПРАВЛЕН)** — веса анализаторов были захардкожены, теперь читаются из конфига стратегии
2. **DRAW underprediction (ИСПРАВЛЕНО)** — модель недооценивала ничьи в 3.6x раз, добавлена калибровка по лигам
3. **Константные параметры (ИСПРАВЛЕНО)** — параметры лиг были одинаковы для всех, теперь индивидуальны

### Реализованные улучшения

**Poisson анализатор:**
- Динамические avg_home_goals/avg_away_goals по лигам
  - Bundesliga: 1.71/1.46 (было 1.52/1.32, +12.5%/+10.6%)
  - Liga Argentina: 1.20/0.83 (было 1.52/1.32, -21%/-37%)
- Динамический Dixon-Coles ρ по лигам
- Динамический draw boost multiplier (от 1.28x до 25.2x)
- Обратная совместимость сохранена

**Интеграция:**
- `src/api/routes/strategies-routes.js` — использует getLeagueParams()
- `src/analytics/utils/league-params.js` — утилита загрузки параметров с кэшированием
- `.omp-lab/league-params.json` — данные по 22 лигам (2023-2024)

### Калибровочные данные

**22 лиги откалиброваны** по avg_goals  
**7 лиг откалиброваны** по DRAW prediction:
- Bundesliga: multiplier 17.3x (было 1.5% DRAW → нужно 26%)
- Eredivisie: multiplier 25.2x (было 1.0% → нужно 25.2%)
- Premier League: multiplier 4.18x (было 5.5% → нужно 23%)
- Serie A: multiplier 3.21x (было 9.0% → нужно 28.9%)
