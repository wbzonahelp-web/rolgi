📡 Доступные API Эндпоинты

GET /api/games
Получить список игр с фильтрацией по лиге, сезону, статусу, датам
GET /api/games/:id
Получить детали конкретной игры со статистикой и событиями
GET /api/teams
Получить список команд с поиском и фильтрацией
GET /api/teams/:id
Получить детали команды с составом игроков
GET /api/players
Получить список игроков с фильтрацией по команде и позиции
GET /api/odds/live/:gameId
Получить live коэффициенты для игры
GET /api/standings
Получить турнирную таблицу лиги
POST /api/loader/load
Запустить загрузку данных (games, teams, players, odds, standings)
