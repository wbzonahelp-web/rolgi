Список матчей​Copy link
Получение списка футбольных матчей с гибкими возможностями фильтрации и сортировки.

Основные возможности:

Поиск по конкретным матчам, лигам, сезонам и командам
Фильтрация по временным периодам (конкретная дата или диапазон)
Отбор матчей по статусу: завершенные, текущие (лайв) или предстоящие
Пагинация результатов (до 1000 матчей за запрос)
Сортировка по дате проведения матча
Примеры использования:

?Date=2025-06-21 - все матчи за конкретный день
?From=2025-06-01&amp;To=2025-06-30 - матчи за период
?LeagueId=england/premier-league&amp;Ended=true - завершенные матчи лиги
?Team=arsenal/hA1Zm19f&amp;Live=true - текущие матчи команды
?BothTeams=villa/ALztxK6e,chelsea/4fGZN2oK - матчи между двумя командами
⚠️ Обязательно укажите хотя бы один параметр фильтрации, иначе запрос будет отклонен.

Команды​Copy link
Поиск команды по заданным критериям поиска.

Параметры поиска:

Поиск выполняется по одному из параметров в порядке приоритета: uid → id → name
При поиске по названию используется частичное совпадение (содержит указанную строку)
Возвращается максимум 100 команд
Обязательные условия:

Должен быть указан хотя бы один из параметров поиска
Query Parameters
uidCopy link to uid
Type:string
Format:uuid
Уникальный идентификатор команды (GUID). Имеет наивысший приоритет при поиске

idCopy link to id
Type:string
Строковый идентификатор команды. Используется если не указан uid

nameCopy link to name
Type:string
Название команды или его часть для поиска. Используется если не указаны uid и id

Responses

200
OK

400
Bad Request

Лиги​Copy link
Получение списка футбольных лиг с возможностью фильтрации по различным критериям.

Варианты использования:

Без параметров - возвращает все доступные лиги
По GUID - получение конкретной лиги (приоритетный поиск)
По ID - поиск лиги по строковому идентификатору
По названию - поиск лиг, содержащих указанную подстроку (регистр не учитывается)
Приоритет фильтров: GUID > ID > название

Если указан GUID, остальные параметры игнорируются. Фильтры по ID и названию могут применяться совместно.

Query Parameters
guidCopy link to guid
Type:string
Format:uuid
Уникальный идентификатор лиги (GUID). При указании возвращается только одна конкретная лига

idCopy link to id
Type:string
Строковый идентификатор лиги для точного поиска

nameCopy link to name
Type:string
Часть названия лиги для поиска (поиск по подстроке, регистр не учитывается)

Responses

200
OK

400
Bad Request

По уникальному идентификатору (leagueUid)

Примечание: Необходимо указать хотя бы один из параметров идентификации лиги.

Матч​Copy link
Возвращает детальную информацию о футбольном матче по его идентификатору.

Включает:

Основные данные матча (команды, счет, статус, время)
Букмекерские коэффициенты (если доступны)
События матча (голы, карточки, замены и др.)
Примеры использования:

Отображение подробной информации о матче в приложении
Получение актуальных коэффициентов для ставок
Просмотр хронологии событий матча
Query Parameters
idCopy link to id
Type:string
Уникальный идентификатор футбольного матча

Responses

200
Объект с полной информацией о матче или сообщение об ошибке, если матч не найден
