Список матчей​Copy link
Извлечение списка матчей. Данные о каждом матче возвращаются в сокращенном варианте (Id, время, статус, счет, названия команд их их ID, сезон, тур, коэффициенты).
Коэффициенты в сокращенном варианте: 1X2, Total. (на момент ближе к закрытию линии)

Для получения полной информации о конкретном матче используется /games/{id}

Одним запросом можно извлечь не более 1000 матчей. Чтобы извлечь остальные, нужно использовать несколько запросов, увеличивая &offset=N.

Например:
&amp;offset=0&amp;limit=10 - отобразит первые 10 матчей
&amp;offset=10&amp;limit=10 - отобразит следующие 10 матчей (пропуская первые 10)

Примеры:
Извлечение всех матчей по id лиги и году сезона
https://api.sstats.net/games/list?leagueid=183&amp;year=2022

Извлечение всех матчей по id сезона 1DC9CB60-0958-11EE-B462-879841420925
https://api.sstats.net/games/list?seasonUid=1DC9CB60-0958-11EE-B462-879841420925

Извлечение всех матчей по id лиги и временному интервалу
https://api.sstats.net/games/list?leagueid=183&amp;from=2022-10-30&amp;to=2022-12-30

Предстоящие матчи команды
https://api.sstats.net/games/list?upcoming=true&amp;team=529

Прошедшие матчи между командами когда они играли друг с другом (Head 2 Head)
https://api.sstats.net/games/list?ended=true&amp;bothTeams=529,541

Type:string
Format:date
Конкретная дата. В выборку будут включены все матчи за выбранный день. Чтобы указать часовой пояс, используйте параметр TimeZone. "2025-06-02"

FromCopy link to From
Type:string
Example
Начальная дата. Если указана только дата без времени, то будут включены все матчи за текущую дату, начиная с полуночи. Если не указывается время с часовым поясом (2025-06-17T14:23:30+02:00), то часовой пояс необходимо передать отдельно в параметре TimeZone Дата + время + часовой пояс: 2025-06-17T14:23:30+02:00 Дата + время: 2025-06-17T14:23:30 Дата + время (без секунд): 2025-06-17T14:23 Дата: 2025-06-17

FromDateCopy link to FromDate
Type:string
Format:date-time
the date-time notation as defined by RFC 3339, section 5.6, for example, 2017-07-21T17:32:28Z

ToCopy link to To
Type:string
Example
Конечная дата. Фильтруются все матчи строго до этой даты. Если указана только дата, без времени, то в выборку включаются все матчи до полуночи указанной даты. Для всех дат, где не указан часовой пояс (+02:00) необходимо указать часовой пояс отдельно в параметре TimeZone Например: если To = 2025-06-02, то в выборку попадут все матчи до 2025-06-02 00:00:00. Т.е матчи за само 2025-06-02 уже выборку не попадают Дата + время + часовой пояс: 2025-06-17T14:23:30+02:00 Дата + время: 2025-06-17T14:23:30 Дата + время (без секунд): 2025-06-17T14:23 Дата: 2025-06-17
