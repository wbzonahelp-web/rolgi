# Games API - Glicko 2 Ratings

## Endpoint: GET /Games/glicko/{id}

Получить рейтинги Glicko 2 и предсказание вероятностей победы команд.

### Path Parameters

- **id** (string, required): Id матча. Sstats Id в виде числа или Flashscore Id в виде строки

### Описание Glicko 2

Glicko-2 - это система рейтингов, разработанная профессором Марком Гликманом. Это усовершенствованная версия системы Glicko, которая учитывает:

1. **Rating (r)** - базовый рейтинг игрока/команды
2. **Rating Deviation (RD)** - неопределенность рейтинга (чем меньше, тем точнее)
3. **Volatility (σ)** - изменчивость результатов во времени

### Преимущества Glicko 2:
- Более точные предсказания по сравнению с ELO
- Учет неопределенности рейтинга
- Адаптация к изменчивости формы команды
- Статистическая обоснованность прогнозов

### Response Structure

```json
{
  "status": "OK",
  "data": {
    "gameId": 1461496,
    "homeTeam": {
      "id": 12345,
      "name": "Team A",
      "rating": 1500,
      "ratingDeviation": 150,
      "volatility": 0.06
    },
    "awayTeam": {
      "id": 67890,
      "name": "Team B",
      "rating": 1450,
      "ratingDeviation": 140,
      "volatility": 0.05
    },
    "predictions": {
      "homeWinProbability": 0.58,
      "drawProbability": 0.24,
      "awayWinProbability": 0.18
    },
    "ratingDifference": 50,
    "confidence": "high"
  },
  "traceId": "..."
}
```

### Response Fields

#### Team Data:
- **id** - ID команды
- **name** - Название команды
- **rating** - Glicko 2 рейтинг (обычно от 1000 до 2000)
- **ratingDeviation** - Отклонение рейтинга (меньше = точнее)
- **volatility** - Волатильность (изменчивость формы)

#### Predictions:
- **homeWinProbability** - Вероятность победы хозяев (0.0 - 1.0)
- **drawProbability** - Вероятность ничьей (0.0 - 1.0)
- **awayWinProbability** - Вероятность победы гостей (0.0 - 1.0)

Сумма вероятностей всегда равна 1.0 (100%)

#### Additional Fields:
- **ratingDifference** - Разница рейтингов (положительная = хозяева сильнее)
- **confidence** - Уровень уверенности: "high", "medium", "low"

### Интерпретация данных

#### Rating (Рейтинг):
- 1000-1200: Слабая команда
- 1200-1400: Средняя команда нижней части таблицы
- 1400-1600: Средняя команда
- 1600-1800: Сильная команда
- 1800-2000: Топ команда
- 2000+: Элитная команда

#### Rating Deviation (Отклонение):
- 0-100: Очень высокая точность (много матчей)
- 100-200: Высокая точность
- 200-300: Средняя точность
- 300+: Низкая точность (новая команда или долгий перерыв)

#### Volatility (Волатильность):
- 0.00-0.03: Очень стабильная форма
- 0.03-0.06: Стабильная форма
- 0.06-0.10: Изменчивая форма
- 0.10+: Очень изменчивая форма

#### Win Probability (Вероятность победы):
- 0.00-0.20: Очень низкая
- 0.20-0.40: Низкая
- 0.40-0.60: Средняя (равные шансы)
- 0.60-0.80: Высокая
- 0.80-1.00: Очень высокая

### Use Cases

1. **Прогнозирование исхода матча**
   - Оценка вероятностей различных исходов
   - Сравнение с букмекерскими коэффициентами

2. **Анализ силы команд**
   - Сравнение рейтингов команд
   - Оценка изменения формы

3. **Value Betting**
   - Поиск недооцененных команд
   - Выявление завышенных/заниженных коэффициентов

4. **Статистический анализ**
   - Оценка точности прогнозов
   - Калибровка моделей

### Example Requests

#### Получить Glicko 2 для конкретного матча
```bash
curl "https://api.sstats.net/Games/glicko/1461496"
```

#### Через наш API
```bash
curl "http://158.69.195.140:3001/api/games/glicko/1461496"
```

### Responses

#### 200 OK
Успешный запрос с данными Glicko 2 рейтингов

#### 404 Not Found
Матч не найден или рейтинги недоступны

#### 400 Bad Request
Некорректный ID матча

### Notes

1. Рейтинги обновляются после каждого матча
2. Для новых команд может быть высокое RD (неопределенность)
3. Долгие перерывы между матчами увеличивают RD
4. Система учитывает силу соперников в прошлых матчах
5. Вероятности основаны на статистической модели

### Related Endpoints

- `GET /Games/{id}` - Полная информация о матче
- `GET /Odds/live/{id}` - Live коэффициенты букмекеров
- `GET /Games/list` - Список матчей с фильтрами
