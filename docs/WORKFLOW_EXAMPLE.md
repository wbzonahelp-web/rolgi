# Пример использования Git Workflow

Этот файл создан для демонстрации правильного workflow с pull request.

## Процесс, который был выполнен:

1. ✅ Создана ветка `feature/example-workflow` от `main`
2. ✅ Добавлен этот файл с примером
3. ✅ Будет сделан коммит с conventional commit сообщением
4. ✅ Будет синхронизация с main (fetch + rebase)
5. ✅ Будет push в удаленный репозиторий
6. ✅ Будет создан Pull Request

## Что демонстрирует этот пример:

- Правильное именование веток (feature/описание)
- Формат conventional commits
- Процесс создания PR
- Чистую историю коммитов

## Следующие шаги:

После merge этой ветки в main, вы можете:
1. Создать новую feature ветку для своей работы
2. Следовать процессу из CONTRIBUTING.md
3. Создавать PR для всех изменений
